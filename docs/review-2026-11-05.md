## 一、方向：命题被证伪了一半，另一半被换了对象

### 1.1 项目自己的贡献句写的是风险产品，六年评审一直在测收益

已发布的两个采用结果都是关于**风险**的：E3 采用 `lots` 臂的决定、以及"14 pp 债券缺口"的争论，都落在回撤与波动上。而 E2 的判定框架是"净 CNY 年均差 + MDE + 375 元门槛"，测的是收益。

把两件事放进同一把尺子（同一窗口、同一复权序列、日频盯市）：

| 组合 | CAGR | 年化波动 | 日频最大回撤 | Sharpe |
|---|---|---|---|---|
| 采用账本 `lots`（50 000，15.1 bp） | 6.01 % | 9.09 % | **−14.50 %** | 0.66 |
| `static` 臂 | 2.62 % | 9.58 % | −20.97 % | 0.27 |
| 510300 买持 | 5.47 % | 21.76 % | −44.75 % | 0.25 |
| 511220 买持（公司债，T+0，在冻结清单内） | 4.91 % | 3.27 % | −7.81 % | **1.50** |
| 518880 买持（黄金） | 15.85 % | 13.48 % | −20.47 % | 1.18 |
| 513100 买持（纳指） | 20.36 % | 22.28 % | −28.49 % | 0.91 |

读法：
- 整套装置对"一只宽基 ETF"换来的是 **32.5 pp 的回撤削减**，代价约 0.5 pp 年收益。这是产品的真实形状，方向文档 §1 却把它写成了"可清成本决策的数量"。
- **511220 单只就在风险调整后压过整个账本（1.50 对 0.66）**，而且它本来就在冻结清单里、T+0。这条比较此前从没有被算过——`probe/` 与 `evidence/` 里没有任何 buy-and-hold 臂。
- 收益侧的主要来源是黄金 + 纳指在 2016–2025 这一段的历史（15.3 %/yr、19.6 %/yr）。**这不是构造的功劳，是这一段行情的功劳**，而项目从未把它作为独立风险写明。

### 1.2 收益侧命题在 5–10 万这个资本上不可判定，且不是数据不够

E2 主格（nav 75 000）的判定原文是 `unmeasurable at this capital`：
- `vol` 臂 +417.27 CNY/yr，CI [−715.60, +1665.74]，**MDE 1 750.05**；
- `rule` 臂 +259.32 CNY/yr，CI [−4.06, +579.63]，**MDE 544.65**，门槛 375。

我复核了 MDE 的算法本身：`newquant/eval/e2.py:126` 是 `MDE_Z * se_annual`，其中 `se_annual = sd*sqrt(12)/sqrt(n/12)`，在 n=120 时等于 `1.0954*sd`——**这与文档 §6 的 `2.8 s/sqrt(120)` 相差恰好 12 倍**（文档写法会得出 45.4 元、直接判 rule 显著）。实现是对的（差分的 lag1 自相关 −0.098、lag12 0.022，独立性成立；Newey-West L=0/3/6/12 给出 542/511/490/450，实现值 544.65 对应 L=0），**错的是文档**。

我还试过"暖机月稀释"这个解释，**被自己的正确计算证伪**：只取 84 个有意向的月份重算，点估计升到 +370.46、但 sd 从 177.57 升到 211.94，**MDE 反而变差到 776.97**；要让 MDE 降到点估计需要 **369 个月 = 30.8 年**。所以此前"剔除死月就能显著"的想法作废。

方向结论：**"用月度配置信号在 5–10 万上跑赢买持"这个命题，不是这一轮证据不足，是这个资本上不可判定。** 继续投预算在上面对同一把锁敲门，是在买一个已知不会到来的答案。

### 1.3 被换掉的对象：从"测收益"改成"测必要性"

第二模型路线（gpt-6.1-sol，max）在第一轮 direction 评审里给的 `pursue` 理由，和 gemini4high 在 cross 轮给的 `explore` 理由，指向同一件事：**问题不是"这套构造能不能赚更多"，而是"这套构造需不需要存在"**——即一个事先写定的、可实际持有的简单政策，能不能在同样的门槛、同样的费率、同样的引擎下复现账本的终值与日频回撤。

这是单边检验：还原得住 → 构造可以退场，账本变简单；还原不住 → 构造第一次有了在**这条路径上**存在的实测理由。两条结果都可行动，都不需要 E2 那种功效。

**评审轮交换（4 条 objection 全部 accepted，outcome `invest · explore`）**：
- R1 [blocker] 会计口径让风险测量未定义 → 我承认，并且它不是"新规则"问题：引擎**本来**每个交易日都在写 NAV（`newquant/replay.py:807-808` → `ReplayResult.daily`，`newquant/replay.py:532`），是 E2/E3 只持久化了月度帧。规则就是 `book.nav(marks_at(sess))` 逐日盯市，不插值、不排除持仓。
- R2 [high] 单路径不能建立跨 regime 优势 → 我承认并**收回"durable"**：12 个起点只能测入场时点敏感性，dispersion 就报成入场敏感性。
- R3 [high] 消融没有隔离 sleeve 收益 → 我承认，并且这一轮自己给出了反例：`no_bond` 变体把**对照组本身**从 62 163.64 打到 55 303（而 lots 是 79 052），所以 +1 542.8 是两个不同账本之差，不是可加的 sleeve 贡献；去掉债券反而把对比抬到 +1 773.4，正是不可加的信号。
- R4 [medium] 预算没乘资本档、也没测过每格耗时 → 我承认并且改成实测：一个四臂 E3 格 22.8 s（120 000 档 19.7 s），单臂 6.5–10.2 s，E2 整轮 17 格 × 3 臂 983.3 s；120 格约 **46 分钟**。
- 新增 R5 [medium]：`target_weights` 把 `dict(MANDATE)` 与"年度再平衡"写死（`newquant/replay.py:507`），所以"买入后不再提交"的臂不是换个 `Arm` 就能跑，必须新增 `kind="hold"`。
- gpt 另打的 [high]：`newquant/replay.py:804` 的 `slot = i + 2 if i + 2 < len(sessions) else i + 1` 让**成交滞后依赖窗口长度**——我核了，成立。它的直接后果是 gemini 在 R4 里建议的"从全窗 daily 切片得 5 年结果、零额外 replay"**不可用**，同时也说明 12 个起点必须各自独立跑。

## 二、架构：底层干净，上层有五个各自成立的缺陷

`venue.py` / `order.py` / `ledger.py` 分层正确、只被上层引用；E2/E3 都调用 `replay.replay()` 而没有分叉引擎。问题在上层：

1. **没有任何测试执行 `replay.replay()`。** `replay()`（`newquant/replay.py:542-862`）、`summarise()`（`:873-947`）、分红/拆分/T+1 路径（`:646-682`）、`fit_rule_theta`（`:462-478`）、`target_weights`（`:497-524`）以及 E1/E2/E3 的 `run`/`render` 全部零覆盖。唯一的护栏是写死的 `E2_CONTROL` 快照（`newquant/eval/e3.py:88-92`），而验证它的测试（`tests/test_e3.py:210`）的期望值正是从同一个常量里拿的。**改掉费率路径、门槛或结算滞后，会得到一个绿色测试套件和一份仍然写着"复现 E2"的报告。**
2. **判定规则可以推荐一个它自己刚刚标为门槛假象的臂。** `_verdict`（`newquant/eval/e2.py:277-302`）里 `frozen` 只是一个标签，对 `adopt` 没有否决权，而 `tests/test_e2.py:177-183` 正好把这个组合钉住了。
3. **TE 三分法把两个原因串了。** `achievable`（`newquant/replay.py:749-755`）按**全部** members 摊、不过门槛，而引擎自己的 `lot_composition`（`:396-402`）按被门槛收缩后的 `k` 摊；于是门槛导致的成员收缩落进了 `granularity_te`。E3 的叙事正是架在这个拆分上的。
4. **两个决定所有结论的常量被复制在五个文件里，且没有任何跨文件恒等断言。** 15.1 bp 在 `replay.py:65`、`e2.py:51`、`e3.py:67`、`feasibility.py:32`、`spread.py:143` 加三个 probe 和一个 test；`THRESHOLD_CNY = 375.0`（`e2.py:61`）是"75 000 的 0.5 %"的手写冻结值，`NAV_PRIMARY` 一动它就不跟随。
5. **"清仓门槛"和"一手"各有多个所有者。** `newquant/eval/` 里三份门槛计算（`e2.py:140-146` 带一个静默 `if value is not None` 丢弃、`e2.py:385-392` 又是 max 后 min、`spread.py:136-152` 整段重建且该模块无人 import），另有两处"最小清仓手数"游走（`feasibility.py:56-69`、`:129-133`），一手作为字面量出现在八处，以及两份互相不一致的 code→sleeve 表（`replay.py:57-62` 10 个码 vs `data/freeze.py:47-53` 15 个码，无子集断言）。另外 `replay.py:103-108` 重述了 `venue.py:34-38` 拥有的费率表——只改 `venue.py:34` 会让引擎继续按旧费率算每一个 E2/E3 数字。

死代码（对本轮结论无影响，但会误导读者）：`replay_fingerprint()`、`FLOOR_CROSSING`、`Cost.cash_bp`、`Instrument.listed_from/listed_to`、`LedgerStore.replay_into()`、`Book.replay_hashes()`、`panel_dates()`、整个 `newquant/eval/spread.py`（244 行、无人 import）、`probe/entry_decomp.py:60` 的 `if False` 分支，以及 `e3.py:568-574` 把 `start/end` 写进报告却用默认窗口建市场。

## 四、下一轮方案（已入账本：idea `etf-composition-carries-the-risk` v2 → decision `next-round-composition-benchmark` seq 147）

### 4.1 命题（单向、可行动、不需要 E2 的功效）

在已实现的 2016-01-04..2025-12-31 路径上、12 个入场日、同一 15.1 bp 门槛与同一 `etf_std` 费率下，**一个事先写定的、可实际持有的简单政策能否复现采用账本的终值与日频风险**。若可以，构造退场；若不可以，构造第一次有了在这条路径上存在的实测理由。

**预先写定的判定（跑之前定，不许事后调）**：
- 复现判据：终值净 CNY 落在 `lots` 的 ±[RETURN_TOL] 内，且日频最大回撤与日频年化波动都不差于 `lots` 超过 [RISK_TOL]；
- 要求在**全部 12 个入场日**上都成立才判"构造退场"；
- `RETURN_TOL` / `RISK_TOL` 必须在跑之前写进 probe 脚本常量并在 summary 里打印（建议起点 ±2 % 终值、+1 pp 回撤/波动，但**由用户定**，不是我看完数字再定）。

### 4.2 臂与格

| 臂 | 定义 | 现状 |
|---|---|---|
| `lots` | 采用账本：45/35/10/10，整手进入，年度再提交 | 已有 |
| `static` | 按权重提交（不经整手规则） | 已有 |
| **`hold`** | 入场日按整手一次买入，之后**不再提交任何目标** | **待实现（`kind="hold"`，R5）** |
| **`fix_a` / `fix_b`** | 两个事前写定的手定整手组合（例：`fix_a` = 510300/511220/518880/513100 各按原 sleeve 权重；`fix_b` = 60/40 两袖） | **待写定** |
| `bh_510300` / `bh_511220` | 买持基准，日频同窗 | **待接进 summary** |

规模：12 入场日 × 5 臂（`lots/hold/fix_a/fix_b/bh`）× 2 资本（50 000、100 000）= **120 格**，按实测 22.8 s/四臂格约 **46 分钟**；市场按入场日建一次、在臂与资本间复用（市场与资本无关），ledger 文件按 (格,臂) 一写、跑前删除。

### 4.3 步骤（按此顺序，每步都有止损点）

1. **单一格 kill probe（先做，最便宜）**：实现 `kind="hold"` + 一个单测（断言 `hold` 臂入场后没有任何成交、且入场有成交）。在 2016-01-04 / 50 000 / 15.1 / measured 上跑 `hold` vs `lots`。**若 hold 已落在复现带内且日频回撤不差，直接判构造退场，12 格网格不必跑。**
2. **复现校验**：同格必须复现 `evidence/e3-summary.json` 的 `lots − static = +1 542.79 CNY/yr` 与 `evidence/e3-ledgers/` 的 ledger head；不符则记 `invalid_experiment` 中止。
3. **写定 `fix_a` / `fix_b` 与两个容差**，写进 probe 常量并在 summary 打印，之后不改。
4. **展开 12 入场日 × 2 资本网格**，每个 (格, 臂) 输出：终值净 CNY、**日频**与月度两种口径的最大回撤/波动、成交数、成本 bp、入场后闲置现金、以及每次入场是否可行（不可行要报 binding code，不许静默跳过）。
5. **三桶对账**（回答 R3，并可回答 §10 第 6 项）：每个臂从初始资本到终值拆成 (i) 持仓价格收益、(ii) 现金拖累（闲置余额按 venue 内货币工具计）、(iii) 取整与门槛项（残差），残差必须小于预先声明的会计容差，且**把对照组自身的移动同时报出**。
6. **修 `newquant/replay.py:804`**：把成交滞后改成与窗口长度无关的固定规则（例如 `slot = min(i + 2, len(sessions) - 1)` 并在最后一笔上显式记 `truncated_by_horizon`），因为 12 个独立起点会在末尾撞到这条分支。
7. **写回文档**：§6 的 MDE 公式（×12）、删掉 §7 第 369 行那句已撤回的话、§4 模块图改成实际路径、§1 的贡献句改成"风险产品 + 其收益来源是 2016–2025 的黄金与纳指、该来源未做独立风险测量"、§8 里 seq 93 的理由改为按 seq 100 重写。

### 4.4 明确不做（本轮）

- 不再跑"净 CNY 显著性"型实验（30.8 年才够分辨率）；
- 不用重叠起点当作 regime 证据；
- 不做前瞻纸面账本对现金的评分（50 000 档 MDE 5 564 对 536）；
- 不重开评审轮（旧 idea 6/6 已永久用尽；新 idea v2 有自己的预算，但只有在 probe 出新证据时才值得再开）。

### 4.5 本轮不做但已记账的债（建议下一轮之后清）

架构五条缺陷里，第 1 条（引擎零测试）与第 4 条（常量五处复制）**在任何进一步结论之前**就该修：加一个"跑 `replay()` 一次、钉住 `static` 臂在 50 000 档的终值与成交数"的回归测试，并把 15.1 bp、资本档、门槛做成单一定义、跨文件断言。否则下一轮的每个数字都仍然建立在一个没人跑过的引擎上。

## 五、一句话结论

方向的前半段（用月度信号在 5–10 万跑赢买持）已在本资本上被判定为不可测量，不是证据不足；项目真正交付的是"用 32.5 pp 的回撤削减、约 0.5 pp 的收益代价、换取一个 2016–2025 黄金+纳指路径的暴露"，而这一点从未被这样写过。下一轮不再去敲那把锁，而是问一个单向、便宜、两种结果都可行动的问题：**一个只买一次、之后什么都不做的政策，能不能复现整个账本。**
